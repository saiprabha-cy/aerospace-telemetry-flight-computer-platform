# Testing Module

## Purpose

This folder contains unit tests for the Aerospace Telemetry and Flight Computer Integrated Development Platform (ATFIDP).

Testing ensures that every subsystem behaves as expected before integration into larger aerospace software systems.

---

## Tested Modules

- Virtual Sensors
- Flight Computer
- Telemetry Engine
- Ground Station
- Health Monitor

---

## Objectives

- Verify software correctness
- Detect regressions
- Improve reliability
- Prepare for embedded firmware migration

---

## Testing Framework

Python unittest
